HTTP 状态码大全（免费速查）

网页打不开时，看状态码就知道问题在哪。下面整理了常见 HTTP 状态码的含义，免费速查，也可以用状态码检测工具直接查网址。

1xx 信息

状态码含义
100 Continue继续发送请求体

2xx 成功

状态码含义
200 OK请求成功
201 Created已创建资源
204 No Content成功但没有返回内容
206 Partial Content返回部分内容（断点续传、视频拖动）

3xx 重定向

状态码含义
301 Moved Permanently永久跳转，搜索引擎会转移权重，换域名、强制 HTTPS 用它
302 Found临时跳转
303 See Other提交表单后跳转到结果页
304 Not Modified内容未变，浏览器使用缓存
307 Temporary Redirect临时跳转，保持原请求方法
308 Permanent Redirect永久跳转，保持原请求方法

4xx 客户端错误

状态码含义
400 Bad Request请求格式错误
401 Unauthorized需要登录或认证
403 Forbidden服务器拒绝访问（没有权限、被防火墙拦截）
404 Not Found页面不存在
405 Method Not Allowed请求方法不被允许
408 Request Timeout请求超时
413 Payload Too Large上传内容太大
414 URI Too Long网址太长
429 Too Many Requests请求太频繁，被限流

5xx 服务器错误

状态码含义
500 Internal Server Error服务器内部错误，多为程序出错
502 Bad Gateway网关错误：反向代理连不上后端服务
503 Service Unavailable服务暂时不可用（维护或过载）
504 Gateway Timeout网关超时：后端响应太慢
521 / 522 / 524Cloudflare 专用：源站拒绝连接 / 连接超时 / 响应超时

怎么用HTTP 状态码大全

  1. 在搜索框输入状态码数字，比如 502。
  2. 看含义判断是你这边的问题（4xx）还是服务器的问题（5xx）。
  3. 需要检测具体网址时，用本站的 HTTP 状态码检测工具。

HTTP 状态码大全常见问题

这个工具免费吗？
完全免费。HTTP 状态码大全不收费、不限次数、不用注册登录，也没有水印。
404 和 403 有什么区别？
404 是页面不存在；403 是页面存在但不允许你访问。
502 和 504 有什么区别？
502 是网关连不上后端，504 是连上了但后端响应太慢超时。
301 和 302 对 SEO 有什么影响？
301 会把原网址的搜索权重转到新网址，302 不会，所以永久换网址要用 301。
