怎么用HTTP 状态码检测

  1. 输入完整网址，比如 http://example.com（不写 http 会自动补上）。

HTTP 状态码检测常见问题

这个工具免费吗？
完全免费。HTTP 状态码检测不收费、不限次数、不用注册登录，也没有水印。
301 和 302 有什么区别？
301 是永久跳转，搜索引擎会把权重转到新网址；302 是临时跳转。网站换域名、强制 HTTPS 应该用 301。
为什么我浏览器能打开，这里显示 403？
有些网站会拦截非浏览器的访问或海外 IP，这种情况下结果仅供参考。
会下载网页内容吗？
只读取响应头，不下载网页正文。
