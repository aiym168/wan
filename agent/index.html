支持 MCP 的 AI 客户端可以直接添加工具站大全的 MCP 服务（Streamable HTTP，无需密钥）：

    "gongjuzhan": { "type": "http", "url": "https://aiym.dpdns.org/dl/mcp" }
  }
}

提供 6 个工具：search_tools（搜索全站工具）、parse_video（抖音 / X / B站等视频解析）、video_to_text（视频转文字）、video_script（视频拆解脚本）、video_to_mp3、media_job_status。

命令行工具 gjz

单个 Python 文件，不需要安装任何依赖：

curl -fsSLo gjz.py https://wan.is-my.app/cli/gjz.py
python3 gjz.py list
python3 gjz.py search 图片
python3 gjz.py video 'https://v.douyin.com/xxxx/'
python3 gjz.py download 'https://x.com/用户名/status/123' -o ~/Downloads
python3 gjz.py text 口播.mp4        # 视频转文字，保存 txt + srt
python3 gjz.py script 'https://v.douyin.com/xxxx/'   # 拆解脚本
