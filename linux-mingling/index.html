文件与目录

命令作用
ls -lah列出文件，含隐藏文件和易读大小
cd 目录切换目录；cd ~ 回家目录，cd - 回上一个目录
pwd显示当前路径
mkdir -p a/b/c递归创建目录
cp -r 源 目标复制目录
mv 源 目标移动或重命名
rm -rf 目录强制删除目录（不可恢复，务必确认路径）
find . -name '*.log'按文件名查找
du -sh *查看各目录占用大小
df -h查看磁盘剩余空间
ln -s 源 链接名创建软链接
tar -czvf a.tar.gz 目录打包压缩；tar -xzvf a.tar.gz 解压

查看与搜索文本

命令作用
cat / less 文件查看文件；less 可翻页，q 退出
head -n 20 / tail -n 20看前 / 后 20 行
tail -f 日志实时追踪日志
grep -rn '关键词' .递归搜索文本并显示行号
wc -l 文件统计行数
sort | uniq -c排序后统计重复行

权限与用户

命令作用
chmod +x 脚本加执行权限

chown 用户:组 文件修改所有者
sudo 命令以管理员身份执行
whoami / id查看当前用户

命令作用

uptime开机时长和负载
systemctl status 服务查看服务状态（systemd 系统）
journalctl -u 服务 -f查看服务日志

命令作用

怎么用Linux / Mac 终端命令

  1. Mac 打开「终端」App（在启动台或聚焦搜索 Terminal）；Linux 打开终端或 SSH 登录服务器。
  2. 在下面搜索你要做的事，比如「解压」「端口」「磁盘」。
  3. 把命令里的中文部分换成你自己的文件名或路径，回车执行。

Linux / Mac 终端命令常见问题

这个工具免费吗？
完全免费。Linux / Mac 终端命令不收费、不限次数、不用注册登录，也没有水印。
Mac 终端和 Linux 命令一样吗？
大部分基础命令（ls、cd、grep、tar、ssh）相同；部分系统命令不同，比如 Mac 没有 ip、free、systemctl，表格里已标注替代命令。
rm -rf 安全吗？
rm -rf 会直接删除且不可恢复，执行前务必用 pwd 和 ls 确认路径，千万不要在不确定的目录下执行。
提示 Permission denied 怎么办？
说明当前用户没有权限，可以在命令前加 sudo，或用 chmod / chown 调整文件权限。
