Windows 蓝屏错误代码免费查询

蓝屏时屏幕上会显示「终止代码」，比如 CRITICAL_PROCESS_DIED。在下面输入代码或关键词，就能看到含义和常见解决办法。免费查询。

最常见

终止代码含义常见解决办法
CRITICAL_PROCESS_DIED（0x000000EF）关键系统进程意外结束运行 sfc /scannow 和 DISM 修复系统文件；卸载最近安装的软件或驱动；检查硬盘健康。
IRQL_NOT_LESS_OR_EQUAL（0x0000000A）驱动访问了不该访问的内存多为驱动问题：更新或回滚最近的显卡、网卡驱动；运行内存诊断（mdsched）。
DRIVER_IRQL_NOT_LESS_OR_EQUAL（0x000000D1）驱动程序访问内存出错，蓝屏常显示出错的 .sys 文件名根据蓝屏上的 .sys 文件名找到对应驱动并更新或回滚（如 nvlddmkm.sys 是 NVIDIA 显卡驱动）。
SYSTEM_SERVICE_EXCEPTION（0x0000003B）系统服务执行时出现异常更新 Windows 和驱动；卸载最近安装的安全软件、虚拟光驱等；运行 sfc 和 DISM。
PAGE_FAULT_IN_NONPAGED_AREA（0x00000050）访问了无效的内存地址检查内存条（mdsched 内存诊断，或重新插拔内存）；更新驱动；关闭超频。
KMODE_EXCEPTION_NOT_HANDLED（0x0000001E）内核模式程序出现未处理的异常看蓝屏提示的驱动文件并更新；进入安全模式卸载最近的驱动或软件。
MEMORY_MANAGEMENT（0x0000001A）内存管理出错优先怀疑内存条：运行内存诊断，关闭 XMP / EXPO 超频，逐根测试内存。
VIDEO_TDR_FAILURE（0x00000116）显卡驱动长时间无响应后重置失败用 DDU 等工具干净卸载后重装官方显卡驱动；关闭显卡超频；检查显卡温度和供电。

硬件与启动

终止代码含义常见解决办法
INACCESSIBLE_BOOT_DEVICE（0x0000007B）启动时无法访问系统盘检查 BIOS 中硬盘模式（AHCI / RAID / VMD）是否被改过；拔插硬盘线；用安装盘进入「启动修复」。
UNMOUNTABLE_BOOT_VOLUME（0x000000ED）无法挂载启动分区从安装 U 盘进入命令提示符运行 chkdsk C: /f；检查硬盘健康（CrystalDiskInfo）。
WHEA_UNCORRECTABLE_ERROR（0x00000124）硬件报告了无法纠正的错误多为 CPU、内存、供电或超频问题：恢复 BIOS 默认值、关闭超频，检查温度和电源。
CLOCK_WATCHDOG_TIMEOUT（0x00000101）某个 CPU 核心长时间无响应关闭超频、更新 BIOS 和芯片组驱动，检查 CPU 温度。
KERNEL_DATA_INPAGE_ERROR（0x0000007A）从磁盘读取内核数据失败硬盘可能有坏道或数据线松动：检查硬盘健康，运行 chkdsk，必要时尽快备份数据。
NTFS_FILE_SYSTEM（0x00000024）NTFS 文件系统出错运行 chkdsk /f 修复；检查硬盘健康状态。
DPC_WATCHDOG_VIOLATION（0x00000133）驱动或硬件处理时间过长更新固态硬盘固件和存储控制器（如 Intel RST）驱动；更新芯片组驱动。
THREAD_STUCK_IN_DEVICE_DRIVER（0x000000EA）线程卡在设备驱动里，常见于显卡重装显卡驱动，检查显卡散热和供电。

系统与更新

终止代码含义常见解决办法
CRITICAL_STRUCTURE_CORRUPTION（0x00000109）内核关键数据被修改卸载可能修改内核的软件（旧版虚拟机、外挂、破解补丁）；检查内存。
SYSTEM_THREAD_EXCEPTION_NOT_HANDLED（0x0000007E）系统线程异常未处理更新或回滚蓝屏提示的驱动；在安全模式下排查。
BAD_POOL_HEADER（0x00000019）内存池头部损坏多为驱动或安全软件冲突：卸载最近的驱动 / 杀毒软件，运行内存诊断。
BAD_SYSTEM_CONFIG_INFO（0x00000074）注册表或启动配置出错进入「启动修复」或使用系统还原点恢复。
KERNEL_SECURITY_CHECK_FAILURE（0x00000139）内核检测到数据结构损坏更新驱动、运行 sfc / DISM，检查内存。
APC_INDEX_MISMATCH（0x00000001）驱动程序内部状态不匹配常见于打印机、显卡驱动或某次系统更新后，可卸载最近的更新或驱动。
SYSTEM_PTE_MISUSE（0x000000DA）页表项使用错误，常与 BIOS 中 PTT / TPM 设置有关更新 BIOS；必要时在 BIOS 中检查安全设置。
UNEXPECTED_STORE_EXCEPTION（0x00000154）存储组件出现意外异常检查硬盘健康、更新存储驱动和固件，关闭第三方杀毒软件试试。

怎么用蓝屏错误代码查询

  1. 记下蓝屏上的「终止代码」和可能显示的出错文件名（如 xxx.sys）。
  2. 在下面搜索框输入代码（可以只输一部分，如 IRQL）或十六进制编号。
  3. 按建议从简单到复杂排查：先更新或回滚驱动、修复系统文件，再检查内存和硬盘。重要数据先备份。

蓝屏代码在哪里看？
蓝屏界面上「终止代码」后面那串英文就是。如果没来得及看，可以在「事件查看器 › Windows 日志 › 系统」里找 BugCheck 事件，或用开源工具 BlueScreenView / WinDbg 分析 C:\Windows\Minidump 里的转储文件。
经常蓝屏是硬件坏了吗？
不一定。大多数蓝屏由驱动或软件冲突引起；如果代码总和内存、硬盘有关，或者重装系统后仍然频繁蓝屏，再重点检查硬件。
蓝屏后电脑进不了系统怎么办？
连续强制关机 2—3 次会进入「Windows 恢复环境」，可以选「启动修复」「系统还原」或「卸载更新」，也可以进入安全模式卸载最近安装的驱动。
