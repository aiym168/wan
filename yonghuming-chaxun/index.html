很多人用同一个 ID 注册了几十个网站，自己都忘了。查一遍，看看当年的论坛、游戏、博客还在不在。

账号侦探怎么查

每个网站的用户主页都有固定的网址格式，比如 GitHub 是 github.com/用户名，CSDN 是 blog.csdn.net/用户名。账号侦探按整理好的规则访问这些公开页面或公开接口，根据返回结果判断主页是否存在，不登录任何账号、不读取主页内容，结果里只有网站名称、是否找到和官方链接。

为什么不查手机号和邮箱

查「手机号或邮箱注册过哪些网站」要调用各网站的注册或找回密码接口，很容易被用来收集他人隐私，所以账号侦探只查用户名对应的公开主页。担心邮箱泄露的话，建议到常用网站的官方安全中心改密码并开启两步验证。

使用提醒

找到只表示这个用户名在该网站有公开主页，不代表是同一个人；没找到也不代表没注册（可能改过名、注销、设了私密，或网站拦截了查询）。请用于自查、查重和防冒用，不要用来骚扰、跟踪他人。

怎么用账号侦探

  1. 在输入框里填你用了好多年的网名或 ID，比如游戏 ID、论坛网名、注册网站时常用的英文名；中文昵称只会在支持中文的平台上查。
  2. 点「开始侦查」，脚印会一边查一边出现，一般半分钟到一分钟查完。
  3. 先点开「热门社交」里的 X、Instagram、微博等按钮确认，再在下面看自动找到的网站，点「打开主页」确认是不是你自己。
  4. 「暂时无法检查」表示网站拦截了查询或响应太慢，可以点旁边的「去看看」到官网自己确认。

账号侦探常见问题

这个工具免费吗？
完全免费，不用注册登录。为了保护各网站和本站服务器，每个 IP 有查询频率限制，正常自查完全够用。
账号侦探是什么？
账号侦探是一个免费的用户名查询工具：输入一个网名或 ID，一次检查 398 个国内外网站有没有同名的公开主页，帮你看清自己的数字足迹。
怎么查自己注册过哪些网站？
把你常用的几个网名、ID 分别输入账号侦探查一遍，找到的网站点开确认是不是你的账号。注册时用的邮箱也可以搜一下邮箱里的「注册成功」「欢迎加入」邮件来补充。
查到了就说明是同一个人吗？
不是。找到只表示这个用户名在该网站有公开主页，常见的名字很多人在用，一定要点开主页自己确认。
显示没找到，就是没注册过吗？
不一定。账号可能改过名、已注销、设成私密，或者网站暂时拦截了查询，结果仅供参考。
能用手机号或邮箱查注册过哪些网站吗？
不能。为了保护隐私、避免被滥用，账号侦探只查用户名对应的公开主页，不支持手机号和邮箱查询。
为什么没有小红书、抖音、微信？
这些平台没有按用户名打开的公开主页，查看必须登录 App，我们不会用伪造的方式去查。X、Instagram、微博等会拦截自动查询，页面里给了一键直达按钮，点开就能确认。
会保存我查询的用户名吗？
不会。用户名只用于这一次查询，服务器不写日志、不存数据库，只在内存里短暂缓存十几分钟的结果，避免重复访问同一个网站。
为什么提示查询太频繁？
为了不给各网站和本站服务器造成压力，每个 IP 每 10 分钟最多 8 次请求（一次侦查通常算 1～2 次），每天 40 次。
可以用来查别人吗？
请只用于自查、查重和防冒用。不要用查到的信息骚扰、跟踪他人，这可能违反法律。
