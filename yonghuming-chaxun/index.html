用户名查询能做什么

很多人在不同网站用同一个网名或 ID。输入你常用的用户名，工具会去 110 个常见网站检查这个用户名有没有对应的公开主页，找到的会给出官方主页链接。常见用途：

  • 自查：看看自己多年前用同一个 ID 注册过哪些网站，找回旧账号，或清理不再使用的公开资料。
  • 起名前查重：新项目、新品牌、新账号想用一个统一的 ID，先看看各大平台是否已被占用。
  • 防冒用：检查有没有人在你没用过的平台上抢注了你的常用名。

查询原理

每个网站的用户主页都有固定的网址格式，比如 GitHub 是 github.com/用户名，CSDN 是 blog.csdn.net/用户名。工具按照整理好的规则访问这些公开页面或公开接口，根据返回结果判断主页是否存在，不登录任何账号、不读取主页内容，结果里只显示网站名称、是否找到和官方链接。

其中约 31 个允许跨域访问的网站直接由你的浏览器查询，其余网站由本站服务器代为查询，服务器有频率限制。哔哩哔哩、百度贴吧、稀土掘金、洛谷这几个平台的主页地址不是用户名，工具用它们公开的用户搜索结果做昵称精确匹配。

为什么不支持手机号和邮箱

查「手机号或邮箱注册过哪些网站」需要调用各网站的注册或找回密码接口，容易被用来收集他人隐私，也会给这些网站带来骚扰，所以本工具只查用户名对应的公开主页。如果担心自己的邮箱是否泄露，建议到对应网站的官方安全中心修改密码并开启两步验证。

怎么用用户名查询

  1. 在输入框里填你常用的用户名（ID），比如注册网站时常用的英文名；中文昵称只会在支持中文的平台上查。
  2. 点「开始查询」，结果会一边查一边出现，一般 10—40 秒查完。
  3. 点「找到」筛选出有公开主页的网站，点「打开主页」确认是不是你自己的账号。
  4. 「暂时无法检查」表示网站拦截了查询或响应太慢，可以稍后再查，或点进官网自己确认。

用户名查询常见问题

这个工具免费吗？
完全免费。用户名查询不收费、不限次数、不用注册登录，也没有水印。
查到了就说明是同一个人吗？
不是。找到只表示这个用户名在该网站有公开主页，常见的名字很多人都在用，一定要点开主页自己确认。
显示没找到，就是没注册过吗？
不一定。账号可能改过名、已注销、设成了私密，或者网站暂时拦截了查询，结果仅供参考。
能用手机号或邮箱查注册过哪些网站吗？
不能。为了保护隐私、避免被滥用，本工具只查用户名对应的公开主页，不支持手机号和邮箱查询。
为什么没有小红书、抖音、微信？
这些平台没有按用户名访问的公开主页，查看必须登录 App，我们不会用伪造的方式去查。X（推特）、Instagram、知乎、微博等会拦截自动查询，页面里给出了主页链接，可以自己点开看。
会保存我查询的用户名吗？
不会。用户名只用于这一次查询，服务器不写日志、不存数据库，只在内存里缓存十几分钟的查询结果，避免重复访问同一个网站。
为什么提示查询太频繁？
为了不给各网站和本站服务器造成压力，每个 IP 每 10 分钟最多查 4 次，每天最多 20 次左右。
可以用来查别人吗？
请只用于自查、查重和防冒用。不要用查到的信息骚扰、跟踪或人肉他人，这可能违反法律。
