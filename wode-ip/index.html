我的 IP 地址常见问题

这个工具免费吗？
完全免费。我的 IP 地址不收费、不限次数、不用注册登录，也没有水印。
为什么显示的 IP 和电脑网络设置里的不一样？

你的网络支持 IPv6 时会优先用 IPv6 访问，这是正常的。
