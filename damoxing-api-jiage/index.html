大模型 API 价格对比常见问题

这个工具免费吗？
完全免费。大模型 API 价格对比不收费、不限次数、不用注册登录，也没有水印。
输入和输出价格为什么不一样？
模型生成（输出）比读取（输入）更耗算力，所以输出价格通常是输入的 3—5 倍。对话、写作类应用输出多，翻译、总结类应用输入多。
缓存命中是什么意思？
重复发送相同的前缀内容（如系统提示词、长文档）时，厂商会缓存起来，再次命中时按很低的价格计费，能大幅降低多轮对话和知识库应用的成本。
