怎么用Mac 快捷键大全

  1. ⌘ 是 Command 键，⌥ 是 Option 键，⇧ 是 Shift 键，Control 是 Control 键。
  2. 在搜索框输入想做的事，比如「截图」「隐藏文件」「强制退出」。
  3. 习惯以后，Windows 的 Ctrl 快捷键大多对应 Mac 的 ⌘。

Mac 快捷键大全常见问题

这个工具免费吗？
完全免费。Mac 快捷键大全不收费、不限次数、不用注册登录，也没有水印。
Mac 怎么剪切文件？
在访达里先 ⌘ + C 拷贝，到目标位置按 ⌘ + ⌥ + V，就是「移动」，相当于剪切粘贴。
Mac 截图保存在哪里？
默认保存在桌面。按 ⌘ + ⇧ + 5，在「选项」里可以改成保存到其他文件夹或剪贴板。
Mac 怎么强制退出卡死的程序？
按 ⌘ + ⌥ + Esc 打开「强制退出应用程序」窗口，选中后点「强制退出」。
