免费二维码美化（带 Logo / 彩色 / 圆点）

把普通黑白二维码变成带 Logo 的彩色圆点二维码，贴在海报、名片上更好看。免费、无水印、可导出高清图。

免费免登录不限次数文件不上传手机电脑都能用

怎么用二维码美化

  1. 输入网址或文字，下方实时生成二维码。
  2. 选择码点和码眼样式，设置前景色（可设渐变）、码眼颜色和背景色。
  3. 需要 Logo 时上传图片，会自动放在中间并提高容错率。
  4. 用手机扫一扫确认能识别，再下载 PNG 或 SVG。

二维码美化常见问题

这个工具免费吗？
完全免费。二维码美化不收费、不限次数、不用注册登录，也没有水印。
加了 Logo 还能扫出来吗？
能。二维码有容错能力，加 Logo 时会自动用较高容错率；Logo 不要太大、颜色对比要明显，下载前用手机扫一下确认。
颜色怎么选才容易识别？
前景色要明显深于背景色，最好深色码配浅色背景；浅色码配深色背景时部分手机可能识别不了。
生成的二维码会过期吗？
不会。内容直接编码在图片里，不经过任何跳转服务，永久有效。
