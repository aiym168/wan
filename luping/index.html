免费在线录屏（免安装、无水印）

不装软件也能录屏：选择要录的屏幕或窗口，录完马上下载，没有水印、不限时长。视频只保存在你自己的电脑上。

免费免登录不限次数录像不上传手机电脑都能用

手机浏览器暂不支持网页录屏，请使用手机自带的录屏功能（iPhone 在控制中心，安卓在下拉快捷开关）。本工具请在电脑上的 Chrome、Edge 或 Firefox 中使用。

怎么用在线录屏

  1. 在电脑上用 Chrome、Edge 或 Firefox 打开本页。
  2. 需要讲解时勾选「同时录制麦克风」，然后点「开始录屏」。
  3. 在弹出的窗口里选择整个屏幕、某个窗口或浏览器标签页；要录声音请勾选「分享音频」。
  4. 录完点「停止」（或点浏览器顶部的「停止共享」），预览后点「下载视频」保存。

在线录屏常见问题

这个工具免费吗？
完全免费。在线录屏不收费、不限次数、不用注册登录，也没有水印。
录屏有时长限制或水印吗？
没有。录多久都可以，视频不加任何水印。录制时间很长时文件会比较大，请留意电脑剩余空间。
录出来是什么格式？
Chrome、Edge 新版本通常直接录成 MP4，其他浏览器录成 WebM。WebM 可以用本站的视频格式转换工具转成 MP4。
为什么录不到电脑声音？
共享整个屏幕时只有 Windows 版 Chrome / Edge 支持录系统声音；共享浏览器标签页时各系统都可以录标签页声音。记得在共享窗口里勾选「分享音频」。
视频会上传吗？
不会。录制和保存都在你的浏览器里完成，视频不会经过任何服务器。
