Windows CMD 常用命令免费速查

电脑出问题时，几条命令往往就能排查和修复。下面整理了 CMD 和 PowerShell 都能用的常用命令，免费速查，可按关键词筛选。

免费免登录不限次数可搜索速查手机电脑都能用

网络排查（CMD / PowerShell 都可用）

命令作用
ipconfig查看本机 IP、网关、DNS
ipconfig /all查看网卡 MAC 地址、DHCP 等完整信息
ipconfig /flushdns清除 DNS 缓存（网页打不开时常用）
ipconfig /release 与 /renew释放并重新获取 IP
ping 网址或IP测试能否连通和延迟，例如 ping baidu.com
ping -t 网址持续 ping，Ctrl + C 停止
tracert 网址查看经过的路由节点
nslookup 域名查询域名解析结果
netstat -ano查看端口占用和对应进程 PID
netsh winsock reset重置网络协议栈（需管理员，重启生效）
netsh wlan show profiles查看保存过的 Wi-Fi
arp -a查看局域网 ARP 表

系统信息与维护

命令作用
systeminfo查看系统版本、安装日期、内存、补丁
winver弹窗显示 Windows 版本号
msinfo32系统信息窗口
sfc /scannow扫描并修复系统文件（需管理员）
DISM /Online /Cleanup-Image /RestoreHealth修复系统映像，sfc 修不好时先运行它（需管理员）
chkdsk C: /f检查并修复磁盘错误（系统盘会在重启时执行）
cleanmgr磁盘清理
powercfg /batteryreport生成笔记本电池健康报告
shutdown /s /t 36001 小时后关机；shutdown /a 取消
shutdown /r /t 0立即重启
slmgr /xpr查看 Windows 激活状态
wmic diskdrive get model,status查看硬盘型号和状态（新版 Windows 可能需改用 PowerShell 的 Get-PhysicalDisk）

进程与服务

命令作用
tasklist列出正在运行的进程
taskkill /PID 1234 /F强制结束指定 PID 的进程
taskkill /IM 程序名.exe /F按程序名结束进程
services.msc打开服务管理
sc query 服务名查看服务状态
net start / net stop 服务名启动 / 停止服务（需管理员）

文件与目录

命令作用
cd 路径切换目录；cd .. 返回上一级
dir列出文件；dir /s 包含子目录
mkdir 名称新建文件夹
copy / xcopy / robocopy复制文件；robocopy 适合大量文件和断点续传
move 源 目标移动或重命名
del 文件删除文件；rmdir /s 删除文件夹（不进回收站，谨慎）
type 文件显示文本文件内容
tree /f以树状图列出目录和文件
cls清屏

命令作用
cmd命令提示符

怎么用Windows CMD 常用命令

  1. 按 Win + R 输入 cmd 回车打开命令提示符；需要管理员权限的命令，在开始菜单搜索「cmd」，右键「以管理员身份运行」。
  2. 在下面搜索你要做的事，比如「DNS」「端口」「修复」。
  3. 复制命令粘贴到窗口里回车执行；删除类命令执行前务必确认路径。

Windows CMD 常用命令常见问题

这个工具免费吗？
完全免费。Windows CMD 常用命令不收费、不限次数、不用注册登录，也没有水印。
sfc /scannow 和 DISM 先运行哪个？
一般先运行 DISM /Online /Cleanup-Image /RestoreHealth 修复系统映像，再运行 sfc /scannow 修复系统文件，都需要管理员权限。
怎么查看某个端口被哪个程序占用？
运行 netstat -ano 找到端口对应的 PID，再在任务管理器「详细信息」里按 PID 找到程序，或用 tasklist | findstr PID。
这些命令会损坏电脑吗？
查询类命令（ipconfig、ping、systeminfo）完全安全。del、rmdir、format、注册表修改等操作会删除或改动数据，执行前一定要确认。
